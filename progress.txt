## Codebase Patterns
- Error constructors return `*CLIError` (pointer), enabling fluent `.WithContext()`, `.WithSuggestion()`, `.WithErr()` chains
- Exit codes: 1=general, 2=auth, 3=validation (includes transition/field/type/user), 4=not-found, 5=permission, 6=rate-limit, 7=network, 8=conflict
- JSON error envelope: `{"error": {"code": "...", "message": "...", "context": {...}, "suggestion": "..."}}`
- Table-driven tests throughout — every constructor should have a row in the test table
- `.gitkeep` files placeholder empty directories; remove when adding real `.go` files
- IOStreams: `Test()` returns `*TestIOStreams` with `.OutBuf`/`.ErrBuf`/`.InBuf` buffers for assertions
- IOStreams: pager tests use `JIRA_PAGER=cat` + `stdoutIsTTY=true` to exercise lifecycle without a real TTY
- IOStreams: `NoPager` and `IsJSON` are public fields — set them before calling `StartPager()`
- Config: `LoadFromPath(path)` for tests; `Load()` for production (uses XDG path)
- Config: profile/alias methods live on `*fileConfig` (concrete type), not the `Config` interface — type-assert when needed
- Config: write-to-temp-then-rename pattern in `Save()` — never write directly to config.toml
- Auth: `keyring.MockInit()` at test start for any test touching `keyringStore`; `keyring.ErrNotFound` is the shared not-found sentinel
- Auth: `TokenStore` interface (StoreToken/RetrieveToken/DeleteToken) — keyring primary, file fallback, `NewTokenStore()` constructor
- Auth: `Resolve()` chain: flags > env > profile. Partial credentials at any level = VALIDATION_ERROR. No creds at all = AUTH_ERROR
- Auth: `ProfileConfig` interface decouples resolver from config package — use `ProfileData` not `config.Profile` to avoid import cycle
- Auth: `NormalizeInstanceURL()` strips scheme, trailing slashes, and /rest/... suffix — call at resolution time, not storage time
- API: `withBaseURL()` (unexported) ClientOption for tests — httptest servers are HTTP, but production base URL is HTTPS; use this to redirect
- API: `Do()` accepts 200/201/204 as success; skips body decode on 204; non-success returns error with status + body
- API: `BrowseURL(key)` constructs `https://{instance}/browse/{key}` — Jira API `self` field is the REST URL, not browser URL
- API: Transport chain order: `retryable(auth(http.DefaultTransport))` — auth headers set before retry wraps
- API: `mapHTTPError()` converts HTTP response → CLIError; `mapNetworkError()` converts Go net errors → CLIError(NETWORK_ERROR)
- API: `ErrorCollection{ErrorMessages, Errors}` mirrors Jira's error response shape; `Summary()` joins both into one string
- API: retryablehttp `PassthroughErrorHandler` is required to let failed responses reach `Do()` for proper CLIError mapping
- API: `IssueFields` custom UnmarshalJSON uses `type Alias` trick + two-pass decode; CustomFields captures anything not in `knownFieldKeys`
- API: LinkedIssue uses `LinkedIssueFields` (subset), not `IssueFields` (full) — linked issue responses are trimmed
- API: Input types use `map[string]interface{}` for Fields (dynamic shape) and `map[string]json.RawMessage` for Update (operation arrays)
- Output: `NewFormatter(ios, asJSON, jqExpr)` — jqExpr implies JSON mode; use `f.IsJSON()` to check mode
- Output: JSON envelopes — `OutputData` (bare), `OutputList` ({data, pagination}), `OutputMutation` ({ok:true, ...}), `OutputDryRun` ({dry_run:true, payload, validation})
- Output: `OutputError(w, err, asJSON)` auto-wraps plain errors as GENERAL_ERROR; renders to stderr
- Output: `PaginationMeta.Total` is `*int` — nil serializes as `null` (use for token-based search)
- Output: `ApplyJQ` strings are printed unquoted; other types as JSON (matches gh CLI --jq behavior)
- Factory: `New()` for production (eager IOStreams), `NewTestFactory(ios, cfg, client)` for tests (pre-wired, no lazy resolution)
- Factory: global flags (Profile, OutputJSON, Quiet, DryRun, JQExpr, Text, etc.) are public fields set by PersistentPreRunE
- Factory: `profileConfigAdapter` + `profileConfigBridge` adapts config→auth without import cycle; test configs use disk TOML
- Factory: `api.WithBaseURL()` (exported) for cross-package httptest; `withBaseURL()` (unexported) for api-internal tests
- Root command: stub group commands (auth, issue, config, alias, search) need `RunE` returning `cmd.Help()` so Cobra `IsAvailableCommand()` returns true (enables typo suggestions)
- Root command: `preRun()` must nil-check config from `f.Config()` — `NewTestFactory(nil)` returns `(nil, nil)` which panics on `.Get()`
- Root command: gofmt auto-aligns struct field tags — when adding `RunE` to Cobra commands, keep `Long:` tag aligned with `Short:` / `Use:`
- Alias commands: `aliasManager` local interface (Aliases/SetAlias/Save) for type-asserting config — same pattern as `profileSetter` and `profileManager`
- Shadow detection in alias set: `cmd.Root().Commands()` dynamically checks all registered commands — avoids hardcoded lists and circular imports
- ADF: `Convert(markdown)` returns `(*Node, error)` — the Node is always type `doc` with `version:1`. Empty string returns valid empty doc. goldmark tight lists use `TextBlock` not `Paragraph` for items
- Pagination: `FetchTokenPage[T]`, `FetchOffsetPage[T]`, `FetchRawArrayPage[T]` — all return `([]T, *output.PaginationMeta, error)`. Use token-based for search, offset-based for paged endpoints, raw-array for plain-array endpoints (e.g., /user/search)
